AMPLIVA STUDIOS PORTFOLIO

1. Your WhatsApp, email and Instagram are already set. To change them, open index.html in a text editor and edit the CONTACT block near the bottom
   (wa = number with country code, no + or spaces).
2. Test it: double-click index.html.
3. Put it online free: drag this whole folder onto app.netlify.com/drop
   (or use Cloudflare Pages / Vercel). Keep index.html and the media folder together.
